# 溶解热/燃烧热数据采集与处理软件 v2.2.5

本版基于 [@Zhao-Zehua](https://github.com/Zhao-Zehua/Dissolution-Combustion) 分支的上游版本 **v2.2.4**（提交 `75abcd0`，上游未发布对应 Release）继续开发，主要变化见下。

## 相比上游 v2.2.4 的主要改动

### 数据导入与原始数据保护

- 导入前检查文件编码、二进制内容、表头、参数名、列数、数值是否有限以及时间戳是否重复。Excel、Word、PDF、图片等文件会直接提示不能导入，而不是改后缀后按文本硬读。
- 导入失败时弹窗说明具体原因（行号、字段名、实际列数），并保留此前已经加载的数据。
- 修复了一个可能导致意外写入原始数据文件的输出路径问题：保存时的 CSV 扩展名、含多个点的文件名、无扩展名文件名都已处理，输出与输入为同一文件时会拒绝保存。
- 原始数据导入后不会被修改，导出的结果另存为 `dissolution.csv` / `combustion.csv`。

### 实验阶段操作提示

- 新增记录前、溶解后、停止加热后和燃烧后的基线判据，满足条件时以彩虹色突出显示下一步应该按的按钮，状态区同时给出文字说明。
- 判据包含温漂速度、前后半窗斜率差、去趋势残差和绝对残差，并会冻结开始记录后第一段合格线性温漂作为初期背景，用来排除仍在明显弛豫的曲线。
- 条件重新失败会立即撤销提示并重新确认；断流、无效读数或时间顺序异常会重新积累整个窗口。
- **软件仅给出建议，不会自动操作仪器**，按钮和快捷键始终可以手动操作。阈值细节见 `docs/LinearBaseline-Guidance.md`。

### 计算与选点

- 溶解热拟合区间的自动选点改为自适应基线噪声的线性区间扩展，降低人为调整拟合范围引入的实验误差（@Takatsuki5028）。
- 溶解热低温平台改为取平台右端（加热开始前）的固定窗口，并以真实谷底和急降段作为下界。
- 修正 SciPy 新版下的积分调用（`simps` → `simpson(..., x=...)`），并对依赖做了版本区间约束。
- 界面上成功算出的量热计常数会在本次运行内记住，重新加载文件、重置区间或切换模块后仍会回填；样品模式下手动修改不会覆盖最近一次标定的值，关闭软件后清除。

### 界面与稳定性

- 修复在模式下拉菜单中选择任意选项后界面卡死的问题：菜单收起前销毁界面会连带销毁弹出菜单，导致事件循环停住；现在改为延后切换。
- 打包脚本随程序附带图标资源，按钮与模式下拉框统一为深蓝底白字样式，不再被 ttkbootstrap 主题覆盖。
- 修复状态区高度被压缩到几乎不可见的问题：该区域用于显示当前判据和等待原因，原先在正常窗口大小下只能看到一条细线。
- 自动化测试从无到有：63 项单元测试，另有真实 Tk 的界面冒烟测试、模式切换测试和打包后 EXE 的启动测试。

## 使用说明

1. 把本附件中的 `Dissolution-Combustion-v2.2.5.exe` 放到**可写的目录**下运行，不需要安装 Python。
2. 连接仪器前请先安装对应的 USB 串口驱动（做过蒸汽压实验的机器通常已经装过）。
3. 启动后先点击左上角的下拉菜单选择工作模式：**数据记录**、**溶解热**、**燃烧热**、**溶解热拟合**。
4. 数据记录：选择串口 → 刷新串口 → 选择溶解热或燃烧热 → 等待记录前基线提示 → 开始记录 → 按提示加料/点火、开始加热、停止加热 → 停止记录 → 填写参数 → 保存数据。
5. 数据处理：用「文件(Ctrl-F)」导入数据（建议用本程序记录的文件）→ 检查自动给出的拟合区间和参数 → 计算 → 「保存(Ctrl-S)」输出 PNG 与 CSV。
6. 完整操作说明见 [`manual/Manual.md`](https://github.com/Feukkor/Dissolution-Combustion/blob/main/manual/Manual.md)。

## 已知限制

- 本轮发布只包含 Windows 版本，macOS 版本由 GitHub Actions 的 macOS runner 构建，构建脚本见 `build_macos.py`。
- 自动选点在点数不足、总时长过短或数据中没有实验温变时仍可能给出无意义的区间，相关分析与建议见 [`docs/PointSelection-Review.md`](https://github.com/Feukkor/Dissolution-Combustion/blob/main/docs/PointSelection-Review.md)。
- 单元测试与界面测试均未连接真实仪器，串口采集部分仍需实机验证。
